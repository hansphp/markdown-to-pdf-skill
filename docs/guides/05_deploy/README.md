# Guías de despliegue y entrega

Esta etapa define cómo documentar la puesta en servicio de una versión y su transferencia a quienes la operan y utilizan. Se consulta antes de instalar, migrar o publicar una entrega.

**Disponibilidad:** todavía no hay guías específicas en esta carpeta.

Guías previstas para los siguientes documentos:

- Plan de despliegue: alcance, requisitos previos, pasos, responsables y comprobaciones.
- Procedimiento de reversión: condiciones para activarlo, recuperación y validación posterior.
- Notas de versión: cambios, compatibilidad, incidencias conocidas e instrucciones necesarias.
- Manual de usuario: tareas, permisos, resultados y solución de dificultades frecuentes.
- Registro de entrega: artefactos, versiones, destinatarios y condiciones de transferencia.

Cada procedimiento deberá identificar la versión y el entorno a los que aplica, además de sus evidencias de ejecución y validación.
