# Guías de requisitos

Esta etapa define cómo documentar las necesidades, el comportamiento esperado y las restricciones de un producto. Se consulta antes de acordar una entrega y cada vez que cambian sus requisitos.

**Guía disponible:** [Guía de elaboración de una especificación de requisitos de software (ERS)](guide_ers.md).

Guías previstas para otros documentos:

- Registro de necesidades: origen, interesados, objetivos y prioridad.
- Catálogo de reglas de negocio: reglas, excepciones, fuentes y vigencia.

La ERS deberá permitir relacionar las necesidades con las decisiones de diseño y la aceptación. Los documentos complementarios se crearán cuando aporten información necesaria; no deberán duplicar las definiciones de la ERS.

La estructura de ocho secciones definida en la guía ERS se aplica a ese tipo de documento y no a todas las guías de esta biblioteca.
