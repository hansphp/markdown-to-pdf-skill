# Guías de construcción

Esta etapa define cómo documentar el trabajo de implementación para que el equipo pueda preparar su entorno, contribuir y mantener el código de forma consistente. Se consulta al incorporar colaboradores y al cambiar las prácticas de desarrollo.

**Disponibilidad:** todavía no hay guías específicas en esta carpeta.

Guías previstas para los siguientes documentos:

- Guía de contribución: flujo de trabajo, revisión y condiciones para incorporar cambios.
- Convenciones de desarrollo: organización, nombres, tratamiento de errores y documentación del código.
- Instrucciones de preparación del entorno: requisitos, configuración y comprobación de funcionamiento.
- Instrucciones de compilación e integración: dependencias, pasos reproducibles y artefactos resultantes.

Los procedimientos deberán poder seguirse con los accesos y herramientas declarados. Sus referencias a requisitos, diseño y pruebas deberán conservarse al modificar la implementación.
