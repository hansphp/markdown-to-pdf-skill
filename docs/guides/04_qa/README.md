# Guías de pruebas y aceptación

Esta etapa define cómo documentar la verificación del producto y la decisión de aceptar una entrega. Se consulta desde la planificación para establecer evidencias y durante la ejecución para registrar resultados.

**Disponibilidad:** todavía no hay guías específicas en esta carpeta.

Guías previstas para los siguientes documentos:

- Plan de pruebas: alcance, riesgos, entornos, datos y criterios de inicio y cierre.
- Especificación de casos de prueba: condiciones, pasos, resultados esperados y requisitos cubiertos.
- Informe de resultados: versión evaluada, evidencias, defectos y limitaciones.
- Acta de aceptación: criterios evaluados, decisión, responsables y reservas expresas.

La documentación deberá relacionar requisitos y criterios de aceptación con sus verificaciones. Ejecutar pruebas o generar un informe no equivale por sí mismo a la aceptación del producto.
