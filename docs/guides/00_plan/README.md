# Guías de gestión y alcance

Esta etapa define cómo documentar la justificación de una iniciativa, sus compromisos y la organización del trabajo. Se consulta al iniciar el producto y al evaluar cambios en su alcance.

**Disponibilidad:** todavía no hay guías específicas en esta carpeta.

Guías previstas para los siguientes documentos:

- Visión y alcance del producto: problema, objetivos, interesados, límites y exclusiones.
- Plan de desarrollo: entregas, responsabilidades, dependencias y criterios de seguimiento.
- Registro de riesgos: impacto, probabilidad, respuesta y responsable.
- Registro y procedimiento de cambios: solicitud, análisis de impacto y decisión.

Los acuerdos de esta etapa deberán poder relacionarse con los requisitos y las entregas del producto. La profundidad se ajustará a su tamaño y complejidad.
