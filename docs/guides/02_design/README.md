# Guías de arquitectura y diseño

Esta etapa define cómo documentar las decisiones de solución que satisfacen los requisitos del producto. Se consulta al diseñar la implementación y al evaluar cambios con efectos técnicos o de uso.

**Disponibilidad:** todavía no hay guías específicas en esta carpeta.

Guías previstas para los siguientes documentos:

- Descripción de arquitectura: componentes, responsabilidades, relaciones y despliegue.
- Registro de decisiones de arquitectura: contexto, alternativas, decisión y consecuencias.
- Diseño de datos: entidades, relaciones, integridad y evolución.
- Especificación de interfaces e integraciones: contratos, errores y compatibilidad.
- Diseño de experiencia de usuario: flujos, interacción, contenido y accesibilidad.

Las decisiones deberán referenciar los requisitos que satisfacen y explicar sus restricciones. Los detalles internos de solución tendrán aquí su lugar principal de definición.
