# Markdown a PDF

Este repositorio contiene un conversor local de Markdown a PDF. Lee [README.md](README.md) para la instalación, los ejemplos y las capturas del resultado.

Para crear un ejemplo o convertir un documento, usa `/markdown-to-pdf`. Su entrada está en `.claude/skills/markdown-to-pdf/SKILL.md`; las instrucciones, el motor y los recursos compartidos con Codex están en `.agents/skills/markdown-to-pdf/`.

Consulta el [SKILL canónico](.agents/skills/markdown-to-pdf/SKILL.md) antes de convertir y el [README del motor](.agents/skills/markdown-to-pdf/README.md) para opciones o cambios de implementación. Los comandos de esa guía parten de la raíz del repositorio.
